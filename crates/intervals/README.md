# `interval-tree`

An augmented interval tree based on relative offsets, for keeping range info for
text editors.

## Code

The code basically follows [roperig] and also borrows heavily from [`intervalTree.ts`] in VS Code.

[roperig]: ../rope/README.md
[`intervalTree.ts`]: https://github.com/microsoft/vscode/blob/main/src/vs/editor/common/model/intervalTree.ts
